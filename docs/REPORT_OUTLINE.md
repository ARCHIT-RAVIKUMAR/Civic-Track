# College project report outline
1. Title page, certificate, acknowledgement, abstract
2. Introduction: problem statement, objectives, scope, limitations
3. Literature / existing systems survey (e.g. municipal grievance portals)
4. System analysis: requirements (functional, non-functional), actors and use-case diagram
5. System design: architecture (layered MVC), package diagram, ER diagram (docs/ER_DIAGRAM.md), class diagram, complaint state diagram, sequence diagram for "assign complaint"
6. Implementation: technology stack, module descriptions, OOP concepts with real classes (see README table), security measures, key code listings
7. Testing: test plan, unit/integration/security test cases and results (`mvn test` output), screenshots
8. Deployment: environment variables, hosting choice and limits
9. Results: screenshots of every role's dashboard
10. Conclusion and future scope (maps, notifications by SMS, mobile app, analytics, cloud image storage)
11. References, appendix (schema SQL, sample test data)
